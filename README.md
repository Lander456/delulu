navod pro lobototo:

1. nainstaluj php a vsechno potrebne
2. nainstaluj podle webu laravel (muzes pracovat i na windowsu, pac to bezi v prohlizeci)
3. najdi si xampp a rozjed si mySQL databazi (aji apache server, pripadne pomuzu) a nakonfiguruj si spravne .env
4. profit

na vetsinu veci se pouzivaji php artisan [option]
commandy abys to zapnul, tak v terminalu zadej poporade 
1. "php artisan migrate" <- vytvori tably v DB
2. "composer run dev"
3. terminal ti rekne kde se appka spustila, kdyz to zadas do URL, tak by ti to melo vyjet

pokud ti terminal vypise mysql error, tak zjisti cos delal spatne s db (chat pomuze celkem dobre, ale aji stackoverflow 
ma odpovedi docela dost)
